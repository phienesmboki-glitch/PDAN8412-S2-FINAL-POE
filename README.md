## Dataset
Kaggle Intel Image Classification: https://www.kaggle.com/datasets/puneet6060/intel-image-classification

## Executed results included in the report
- 14,034 training images and 3,000 test images across six scene classes.
- 0 unreadable/corrupt images found in the training audit.
- Baseline test accuracy: 81.23%; test loss: 0.5037; macro-F1: 0.8109.
- 563 of 3,000 test images were misclassified.
- Baseline best validation loss: 0.1763; retrained best validation loss: 0.5556.

## Important scope note
This is a natural-scene image classifier, not facial recognition. It must not be used for identity recognition or access-control decisions.
